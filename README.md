# 청년알리미E - Flutter 앱

청년들을 위한 정책 정보와 일정 관리 앱입니다.

## 🚀 주요 기능

### 📅 캘린더
- 월별 캘린더 뷰
- 일정 추가/삭제 (스와이프로 삭제)
- 오늘의 일정 목록

### ⭐ 즐겨찾기
- 정책 정보 북마크
- 상세 정보 보기
- 즐겨찾기 토글 기능

### 🤖 AI 챗봇
- 정책 문의 AI 어시스턴트
- 실시간 대화 기능
- 추천 질문 버튼

## 🎨 UI/UX 특징

- **모던한 디자인**: Material Design 3 적용
- **애니메이션**: 부드러운 탭 전환 애니메이션
- **특별한 하단 네비게이션**: 중앙 챗봇 버튼이 튀어나오는 디자인
- **반응형 레이아웃**: 다양한 화면 크기 지원

## 🛠 기술 스택

- **Flutter**: 3.x
- **Dart**: 최신 버전
- **HTTP**: API 통신
- **Material Design**: UI 컴포넌트

## 📱 화면 구성

1. **홈 화면** (준비 중)
2. **즐겨찾기**: 정책 북마크 관리
3. **챗봇**: AI 정책 상담
4. **캘린더**: 일정 관리
5. **더보기** (준비 중)

## 🚀 실행 방법

```bash
# 의존성 설치
flutter pub get

# 앱 실행
flutter run
```
